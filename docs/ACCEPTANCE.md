## 2. 申报书扩展方向深度实现

在项目初审通过后，团队严格依照《申报书》规划的工业级进阶扩展方向完成了深度技术攻关与代码扩展：

### 2.1 ST 到 IL 字节码编译器与虚拟机执行流 (`compiler.mbt`, `vm.mbt`)
- **技术突破**：打通了结构化文本 (ST) 高级语法到指令表 (IL, Instruction List) 字节码的直接代码生成。
- **算子与控制流**：支持算术表达式 (`+`, `-`, `*`, `/`, `MOD`)、逻辑布尔运算 (`AND`, `OR`, `XOR`, `NOT`)、关系比较运算 (`=`, `<>`, `>`, `<`, `>=`, `<=`)，以及 `IF-THEN-ELSE` 条件跳转与 `WHILE-DO` 循环。
- **IL 虚拟机机制**：实现了基于 CR 累加器的虚拟机寄存器模型，新增 `Ge`, `Le`, `Mod`, `Jmpcn` (条件为假跳转) 以及 `reset` 周期重置机制，完美契合 IEC 61131-3 IL 标准。

### 2.2 Modbus RTU 物理层二进制帧与 CRC16 校验 (`modbus_rtu.mbt`)
- **工业现场通信**：在现有 Modbus TCP 协议层基础上，新增了完整的 Modbus RTU 二进制编解码模块。
- **CRC-16/MODBUS 算法**：基于纯 MoonBit 实现了工业标准 CRC-16 循环冗余校验算法（多项式 `0xA001`，初始值 `0xFFFF`，低位在前、高位在后），支持请求帧与异常/正常响应帧的双向解析与校验。

### 2.3 高频扫描周期基准压测套件 (`bench_test.mbt`)
- **50,000 次连续扫描周期压力测试**：验证电机自锁梯形图在 50,000 周期连续运行下的状态确定性、时钟推进准确性及自锁保持安全性。
- **1,000 次 PID 闭环调节收敛测试**：在模拟一阶滞后工业被控对象下，PID 控制器迅速无超调逼近目标设定值。
- **10,000 次虚拟机循环执行**：ST 代码编译为 IL 字节码后，在虚拟机上连续高负载循环执行，保障累加器与内存映像稳定无泄漏。
- **5,000 帧 RTU 报文与 CRC 校验吞吐测试**：验证工业总线序列化与校验的高吞吐与零错误率。

## 3. 本地 100% 验收复现流程

评委与开发者可在任何安装有 MoonBit 的环境执行以下命令一键复现：

```bash

moon check

# 2. 执行全量 41 项单元与性能基准测试
moon test

# 3. 运行 CLI 工业场景仿真演示
moon run cmd/main
```
